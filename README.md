# Codex Pulse Windows 内测版

在 Windows 托盘查看 Codex 用量、额度和重置动态。

**[下载 v0.1.3-beta.1 内测安装包](https://github.com/ChaoJiTuoLuKING/codex-pulse-windows-app/releases/tag/v0.1.3-beta.1)** · [测试与反馈说明](TESTING.md)

本仓库仅提供 Windows 安装包和使用说明，不包含应用源码。安装包内部版本为 0.1.3，发布标记为 v0.1.3-beta.1。

## 0.1.3 更新

- 修复托盘图标轮廓过暗：跟随任务栏主题，深色任务栏用白色边框，浅色任务栏用深色边框；没有额度数据时依然可见。
- 包含 0.1.2 的面板定位、日历越界及安装器退出确认修复。
- Windows CI 全部通过；发布者反馈安装包实测正常。完整通知、自启及多屏矩阵仍按内测清单逐项验证。
- 可直接下载 EXE，也可下载 `Codex-Pulse-0.1.3-windows-x64.zip`（含安装包、中文说明与校验值），方便通过 QQ 转发。
- 建议从托盘退出旧版本后覆盖安装，无需先卸载。

## 适用范围

首轮面向 Windows 11 x64（Intel / AMD）小范围内测。Windows 10、Windows ARM 和 WSL 不在本轮已验证范围。

Windows CI 已通过编译、安装、启动、通知 URI 唤起、运行中升级和卸载测试，并检查了静态 CRT 依赖。真实桌面上的通知、托盘、焦点、自启及显示缩放仍待内测验证，**不代表正式版或全部功能已验收**。

## 安装与启动

1. 打开上方发布页，在 Assets 中下载 `CodexPulse_0.1.3_x64-setup.exe`；不要下载 GitHub 自动生成的 Source code 压缩包。
2. 安装包未签名，可能出现 SmartScreen 提示。确认下载地址和校验值后再决定是否继续；如被系统策略阻止，请反馈，不要关闭安全防护。
3. 按安装向导完成安装，从开始菜单打开 Codex Pulse。
4. 程序默认进入托盘、不弹面板；在右下角托盘（可能位于隐藏图标区域）找到图标，单击打开。
5. 用量未读取时，通过托盘菜单选择 Codex 目录，通常是用户目录下的 `.codex`。

## 已知问题与边界

- 已修复后台服务未就绪时缺少退出确认导致的升级超时，并通过对应回归；若仍遇升级失败，请保留错误提示并反馈。
- 通知中心真实点击、通知撤回、开机自启及完整多屏缩放矩阵仍需继续验证。
- 点击通知按设计不打开面板；首次启动不弹窗口也是正常行为。
- 卸载保留应用设置和通知去重记录，不删除 Codex 日志目录。
- 当前没有软件自动更新；后续版本通过此仓库下载安装。

出现崩溃、统计明显错误、通知过多、安装或升级失败时，请优先反馈。详细步骤见 [TESTING.md](TESTING.md)。

重置动态来自独立网络接口，不依赖本机是否安装 Codex。接口限流时按倒计时等待重试；没有 Codex 记录时额度灯显示灰色。
