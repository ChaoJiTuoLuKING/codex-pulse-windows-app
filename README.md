# Codex Pulse Windows

在 Windows 托盘查看 Codex 用量、额度和重置动态。

**[下载最新版 v0.1.5](https://github.com/ChaoJiTuoLuKING/codex-pulse-windows-app/releases/latest)** · [测试与反馈说明](TESTING.md)

本仓库仅提供 Windows 安装包和使用说明，不包含应用源码。安装包内部版本为 0.1.5，发布标记为 v0.1.5。

## 0.1.5 更新

- 修复切换 Codex 账号后额度不一致：刷新会重新读取当前登录账号，核对稳定账号 ID；无法确认身份或查询失败时清空旧额度并显示原因。
- 支持连续切换多个账号；打开面板、点击刷新会发起重读。面板显示时每 5 秒检查一次账号变化，检测和网络请求有延迟，不承诺切号瞬间同步。
- 主面板、动态全文和日历详情按完整内容适配，先移动到屏幕工作区内，空间不足再整体缩小，不出现横向或纵向滚动条。
- 保留日历展开/收起动画，完善额度查询子进程退出回收。
- 可直接下载 EXE，也可下载 `Codex-Pulse-0.1.5-windows-x64.zip`（含安装包、中文说明与校验值）。建议从托盘退出旧版本后覆盖安装，无需先卸载。

## 适用范围

支持 Windows 11 x64（Intel / AMD）。Windows 10、Windows ARM 和 WSL 不在本轮已验证范围。

Windows CI 已通过编译、安装、启动、通知 URI 唤起、运行中升级和卸载测试，并检查了静态 CRT 依赖。0.1.5 已根据使用反馈转为正式发布。

## 安装与启动

1. 打开上方发布页，在 Assets 中下载 `CodexPulse_0.1.5_x64-setup.exe`；不要下载 GitHub 自动生成的 Source code 压缩包。
2. 安装包未签名，可能出现 SmartScreen 提示。确认下载地址和校验值后再决定是否继续；如被系统策略阻止，请反馈，不要关闭安全防护。
3. 按安装向导完成安装，从开始菜单打开 Codex Pulse。
4. 程序默认进入托盘、不弹面板；在右下角托盘（可能位于隐藏图标区域）找到图标，单击打开。
5. 用量未读取时，通过托盘菜单选择 Codex 目录，通常是用户目录下的 `.codex`。
6. 当前账号额度需要已安装且已登录的 Codex 桌面端或 CLI；协议无法提供稳定账号 ID 时请更新 Codex 后重试。Pulse 不读取凭据内容。

## 已知问题与边界

- 已修复后台服务未就绪时缺少退出确认导致的升级超时，并通过对应回归；若仍遇升级失败，请保留错误提示并反馈。
- 消耗总量仍按所选目录的本地历史统计，不会按当前账号自动过滤。
- 极小屏幕工作区会整体缩小内容，字号也会变小。
- 点击通知按设计不打开面板；首次启动不弹窗口也是正常行为。
- 卸载保留应用设置和通知去重记录，不删除 Codex 日志目录。
- 当前没有软件自动更新；后续版本通过此仓库下载安装。

出现崩溃、统计明显错误、通知过多、安装或升级失败时，请优先反馈。详细步骤见 [TESTING.md](TESTING.md)。

重置动态来自独立网络接口，不依赖本机是否安装 Codex。接口限流时按倒计时等待重试；无法读取当前账号额度时额度灯显示灰色。
